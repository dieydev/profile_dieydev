## 🚀 Hướng Dẫn Cài Đặt & Chạy Cục Bộ

```bash
# 1. Clone mã nguồn về máy tính
git clone https://github.com/dieydev/profile_dieydev.git
cd profile_dieydev

# 2. Cài đặt các gói phụ thuộc
npm install

# 3. Khởi chạy môi trường phát triển (Dev Server)
npm run dev
```

Mở trình duyệt và truy cập: **[http://localhost:3000](http://localhost:3000)** (hoặc `http://localhost:3001`).

```bash
# Build mã nguồn cho môi trường production
npm run build
```

## 🌐 Triển Khai Lên Vercel (1-Click Deploy)

Repository này đã được cấu hình sẵn tệp [`vercel.json`](file:///d:/Profile/vercel.json) với định tuyến SPA:

1. Đăng nhập vào [vercel.com](https://vercel.com) bằng tài khoản GitHub của bạn.
2. Nhấn **Add New...** -> **Project**.
3. Chọn repository `dieydev/profile_dieydev`.
4. Vercel tự động nhận diện cấu hình:
   - **Framework Preset**: `Vite`
   - **Build Command**: `vite build`
   - **Output Directory**: `dist`
5. Bấm **Deploy**. Sau khoảng 30 - 60 giây, website của bạn sẽ hoạt động chính thức trên toàn cầu!
